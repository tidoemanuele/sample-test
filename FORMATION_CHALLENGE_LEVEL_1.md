# 🆘 AI Formation Challenge Level 1: Emergency Media Player Crisis

## 🚨 Emergency Briefing

**URGENT ALERT**: The production media player is completely down! The entire development team is on vacation and you're the only developer available. Users are complaining that the video player won't even load, and management is breathing down your neck.

**Your Mission**: Get the media player operational ASAP and ensure users have a fully functional video experience.

## ⚙️ Critical Setup - Prompt Logging

**BEFORE YOU START**: Enable prompt logging for evaluation:

```bash
npm run setup-prompt-logging
```

This sets up automatic logging of every prompt you send to Claude Code, allowing instructors to provide feedback on your AI prompting techniques during this emergency scenario.

## 📋 Student Journey: Emergency Response Protocol

### Phase 1: 🆘 Crisis Response (Infrastructure Repair)

**Situation**: The player won't even start. Something is fundamentally broken.

#### Crisis Response Todos:

- [ ] **EMERGENCY**: Clone the repository and assess the damage

  ```bash
  git clone https://github.com/tidoemanuele/sample-test.git bigscreen-challenge
  cd bigscreen-challenge
  git checkout challenge-level-1
  ```

- [ ] **CRITICAL**: Fix build system errors preventing player from starting

  - Run `npm install` and fix any dependency issues
  - Resolve build configuration problems
  - Get the development server running with `npm run start`

- [ ] **URGENT**: Debug player initialization failures

  - Fix runtime errors preventing player from loading
  - Use browser console to identify and resolve critical errors
  - Work with AI to systematically debug infrastructure issues

- [ ] **VALIDATE**: Confirm basic player functionality
  - Player loads without errors
  - Video starts playing automatically
  - Basic playback controls work

**Success Criteria**: Media player loads and plays video content successfully.

---

### Phase 2: 🔍 Damage Assessment & User Experience Audit

**Situation**: Player works, but users are still complaining about missing functionality.

#### Discovery & Analysis Todos:

- [ ] **INVESTIGATE**: Conduct comprehensive functionality audit

  - Test all visible player controls
  - Identify what features are working vs. missing
  - Document user experience gaps

- [ ] **USER FEEDBACK**: Analyze the core usability problem

  - Users can't seek/scrub through video content
  - No visual seek bar or timeline controls
  - Programmatic seeking exists but no UI access

- [ ] **RESEARCH**: Understanding current seek capabilities

  - Investigate existing seek functionality in the codebase
  - Test programmatic seek commands in console
  - Identify the gap between backend capability and frontend UI

- [ ] **DECISION**: Plan user experience enhancement
  - Recognize that a seek bar is essential for user satisfaction
  - Decide to implement missing seek UI controls
  - Set goal to provide complete video navigation experience

**Success Criteria**: Clear understanding of missing functionality and plan for implementation.

---

### Phase 3: 🚀 Innovation & User Experience Enhancement

**Situation**: Time to go beyond "just working" and create a great user experience.

#### Innovation Implementation Todos:

- [ ] **DESIGN**: Collaborate with AI to design seek bar UI

  - Research HTML5 video seek bar best practices
  - Design visual timeline with current position indicator
  - Plan responsive design that works on different screen sizes

- [ ] **IMPLEMENT**: Build seek bar HTML structure

  - Create seek bar container and progress elements
  - Add time display (current time / total duration)
  - Implement proper CSS styling for professional appearance

- [ ] **INTERACTIVE**: Wire up seek bar functionality

  - Connect seek bar to existing player seeking capabilities
  - Implement click-to-seek and drag-to-seek behaviors
  - Add visual feedback for hover states and active seeking

- [ ] **ENHANCE**: Polish the user experience

  - Add smooth visual transitions and animations
  - Improve volume control
  - Collapsible video debug panels

- [ ] **TEST**: Comprehensive functionality validation
  - Test seeking accuracy and responsiveness
  - Verify visual feedback and state management
  - Confirm cross-browser compatibility

**Success Criteria**: Fully functional seek bar that provides excellent user video navigation experience.

---

### Phase 4: 🎖️ Mission Complete & Professional Practices

#### Documentation & Delivery Todos:

- [ ] **DOCUMENT**: Record your emergency response and enhancements

  - Document what infrastructure issues were resolved
  - Explain the seek bar implementation approach
  - Create user guide for the new functionality

- [ ] **COMMIT**: Create professional git workflow

  - Make focused, descriptive commits for each phase
  - Use proper commit message conventions
  - Demonstrate clean development practices

- [ ] **REPORT**: Executive summary for management

  - Summarize the crisis response and timeline
  - Highlight the added value beyond just "fixing" the problem
  - Demonstrate proactive problem-solving approach

- [ ] **CELEBRATE**: Reflect on the learning journey
  - From crisis response to feature innovation
  - Systematic debugging with AI collaboration
  - Transforming "broken" into "better than before"

**Success Criteria**: Professional delivery with documentation and clear communication of value added.
