# Student Prompt Logs

This directory contains logged prompts from students working on AI Formation challenges.

## Purpose

- **Student Evaluation**: Track how students interact with AI tools
- **Feedback Generation**: Enable instructors to provide targeted feedback on prompting techniques
- **Learning Analytics**: Understand common patterns and difficulties in AI-assisted programming

## File Format

Prompt logs are saved as `prompt_YYYY-MM-DD_HH-MM-SS.md` with the following structure:

```markdown
# Student Prompt Log
**Timestamp:** [ISO timestamp]
**Session ID:** [unique session ID]

## Original Prompt
[student's full prompt here]

## Context
- Working Directory: [current directory]
- Git Branch: [current branch if applicable]
```

## Privacy Note

These logs are used solely for educational evaluation and feedback purposes. They help instructors understand student progress and provide personalized guidance on effective AI prompting strategies.
