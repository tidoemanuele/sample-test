🔍 Investigation Strategy

Follow this systematic approach to understand the project structure and identify issues

Claude Code Investigation Commands

Project Structure Analysis 
claude "Analyze the project structure and identify the main entry points,
build configuration, and dependency management approach"
Build Configuration Review 
claude "Review the webpack config, package.json scripts, and build setup.
Identify any configuration issues or missing dependencies"
Error Detection 
claude "Look for any syntax errors, import issues, or missing files
that might prevent the project from starting"

🛠️ Resolution Approach

Once you've identified the issues, follow this methodical approach to fix them

🎯 Targeted Fixes

Address one issue at a time, testing after each fix to ensure progress

🔄 Live Reload Development

Run npm start once - live reload automatically refreshes the browser when you make changes

📚 Context Awareness

Consider the broader system impact of each change

Resolution Pattern

Fix Systematic Approach 
claude "Fix the [specific issue] by [proposed solution].
Ensure this change is compatible with the existing architecture
and doesn't introduce new problems"
Document the Change 
claude "Document what was fixed and why this solution was chosen"
