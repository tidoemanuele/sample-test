🛠️ Getting Started

Ready to begin your AI Formation journey? First fork the repository to create your own copy, then clone your fork to start working on the challenges.

Essential Setup Steps

Step 1: Fork the repository on GitHub by clicking the "Fork" button at github.com/tidoemanuele/aiformation

⚠️ Important: Uncheck "Copy the main branch only" to fork all challenge branches!

Step 2: Clone Your Fork (replace YOUR-USERNAME) 
git clone https://github.com/YOUR-USERNAME/aiformation.git

🎯 Why Fork? Forking allows you to push changes to your own repository and create pull requests back to the original repo. This enables our GitHub Actions to run automated tests on your submissions!

🚀 Next Step: After cloning your fork, navigate to the repository and open challenges/level-1-intro.html to start your Level 1 challenge!
